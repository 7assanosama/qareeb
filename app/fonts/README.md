# خط القرآن الكريم — KFGQPC Uthmanic Script HAFS

يعرض المشروع الآيات القرآنية بالخط الأصلي **KFGQPC Uthmanic Script HAFS**
(الإصدار 0.09) — خط الرسم العثماني المستخدم في مصحف المدينة المنورة, الصادر
عن مجمع الملك فهد لطباعة المصحف الشريف.

## الملف

- `app/fonts/uthmanic-hafs.otf` — النسخة الأصلية بتوقيع KFGQPC الرقمي (جدول
  DSIG), وجداول OpenType كاملة:
  - **GSUB**: `init`, `medi`, `fina`, `liga`, `calt` (23 lookup سياقي) —
    أشكال الحروف والربط القرآني.
  - **GPOS**: `mark` (16 lookup), `mkmk`, `curs` — تموضع التشكيل والعلامات.
- الاسم الرسمي للعائلة: `KFGQPC Uthmanic Script HAFS` (Regular 400).

## طريقة التوصيل

- يُحمَّل عبر `next/font/local` في `app/layout.tsx` (متغير CSS
  `--font-kfgqpc`, `weight: 400`, `display: swap`, `preload: true`).
  الملف يُقدَّم دون أي تعديل, فيبقى التركيب الرسومي (GSUB/GPOS) سليمًا.
- سلسلة الاستخدام في `app/globals.css`:

  ```css
  --font-quran: var(--font-kfgqpc), "KFGQPC Uthmanic Script HAFS", serif;
  ```

  أي: نسخة المشروع المستضافة أولًا, ثم نسخة الزائر المثبتة محليًا بالاسم
  الرسمي, ثم الخط الاحتياطي النظامي.

## الترخيص

الخط ملك مجمع الملك فهد لطباعة المصحف الشريف (KFGQPC), المدينة المنورة,
المملكة العربية السعودية (http://fonts.qurancomplex.gov.sa). الترخيص يسمح
باستخدامه ونسخه وتوزيعه **مجانًا** دون تعديل أو هندسة عكسية أو بيع, مع
الإبقاء على الترخيص المصاحب. لذا:

- لا تُعدِّل ملف الخط ولا تُغيّر أسماءه الداخلية.
- أبقِ هذا الملف توثيقًا للترخيص المصدر والمنشأ.

## ملاحظات فنية

- الخط ببنية TrueType sfnt (امتداد .otf)؛ المتصفحات تتعرف على المحتوى لا
  الامتداد, و`next/font/local` يتعامل معه سليمًا.
- النص القرآني (نسخة QPC Hafs Unicode, `aya_text_unicode`) مغطى بالكامل: كل
  التشكيل وعلامات الوقف والمد والأرقام الهندية مدعومة في cmap. النص
  (lib/content/quran/quran.json) يستخدم الآن المحارف التي يتوقعها هذا الإصدار
  من الخط؛ المحرف U+FEFF (علامة عرض صفري غير مرئية) لم يعد موجودًا في النص.
- ميزات OpenType المستخدمة في الشكل (`init/medi/fina/liga/calt/mark/mkmk/curs`)
  مفعّلة افتراضيًا في المتصفحات؛ القاعدة في `app/globals.css` تكتفي بـ
  `"kern" 1, "rlig" 1` ولا تعطّل أو تفرض أي ميزة أخرى.

## سلوك أرقام الآيات (مهم)

الخط يُركِّب **الأرقام الهندية وحدها** (١ وحتى ٢٨٦ — كل أرقام آيات المصحف)
عبر GSUB في **زخرفة علامة آية واحدة** تحمل الرقم داخلها (تحقق قياسي: ٢٨٦/٢٨٦
رقم آية تُرسم كزخرفة واحدة, وقياس بكسلي أثبت اختلاف رسم كل رقم داخل الزخرفة).

النتائج العملية:

- **الطريقة الصحيحة** لإخراج علامة رقم الآية: كتابة الأرقام وحدها
  (`toArabicDigits(ayah.number)`) — هذا ما يفعله `QuranText`.
- **لا تضع علامة ۝ يدويًا قبل الأرقام**: ذلك يُرسم زخرفتين متجاورتين
  (علامة فارغة ۝ ثم زخرفة الرقم) — قياس فعلي: عرض `۝١` = ضعف عرض `١`.
- المحارف خارج نطاق أرقام الآيات (مثل ٩٩٩) تُجزَّأ: زخرفة لأطول بادئة
  مطابقة لرقم آية موجود ثم باقي الأرقام منفصلة — لا يستحق الانتباه لأن
  أرقام الآيات كلها ≤ ٢٨٦.
- عند فشل تحميل الخط (احتياطي), يظهر الرقم وحده داخل شارة الخلفية
  الناعمة, ويبقى `aria-label` يصف رقم الآية.
